The Chat App made for website is a real-time messaging website with one-on-one and group chat features. It has forgot password features with email verification. Users can send text, photos, documents, audio, and access the camera in both one to one and group chat. It has profile management-for updating full name, email and profile picture. It has -mark as unread, delete chats, leave group,-block/unblock users, and -dark/light mode. Group chats allow adding members, editing group names, and changing group profile pictures. Using more than 25 api endpoints, i have done all this features.
